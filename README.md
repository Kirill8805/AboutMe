# Сайт-портфолио

Статический сайт-портфолио IT-проектов. Чистый HTML/CSS/JS, без сборки — открывается двойным кликом по `index.html` или размещается на любом хостинге.

## Структура

```
index.html        — Главная (первый экран, избранные проекты, примеры сайтов, компетенции, контакты)
projects.html     — Все проекты + фильтр по категориям
project.html      — Детальная страница проекта (шаблон, открывается как project.html?id=...)
sites.html        — Примеры продающих сайтов
assets/css/styles.css  — стили (светлая тема, дизайн-система)
assets/js/data.js      — ДАННЫЕ: проекты и сайты (редактируется руками)
assets/js/app.js       — логика рендера, фильтры, форма, анимации
```

## Как добавить проект

Откройте `assets/js/data.js` и добавьте объект в массив `projects`:

```js
{
  id: "my-project",              // латиницей, без пробелов — попадёт в ссылку
  title: "Название",
  tagline: "Короткий подзаголовок",
  category: "Автоматизация",      // появится в фильтре автоматически
  status: "Реализован",           // "Реализован" | "Прототип" | "Концепция"
  featured: true,                 // true — показать на главной
  accent: "#2f54eb",              // фирменный цвет полоски на карточке
  cover: "assets/img/my.jpg",     // путь к обложке (пусто — плейсхолдер)
  description: "Описание проекта.",
  tasks: ["Задача 1", "Задача 2"],
  features: ["Возможность 1", "Возможность 2"],
  technologies: ["Web", "Backend"],
  gallery: ["assets/img/1.jpg", "assets/img/2.jpg"],  // скриншоты
  demoUrl: "https://..."          // пусто — кнопка демо неактивна
}
```

## Как добавить пример сайта

В тот же файл, массив `sites`:

```js
{
  id: "shop",
  title: "Интернет-магазин",
  category: "Торговля",
  accent: "#f08c00",
  preview: "assets/img/shop.jpg",
  demoUrl: "https://работающий-сайт.kz"   // откроется в новой вкладке
}
```

## Контакты и форма

- Ссылки WhatsApp / Telegram / Email меняются в `data.js` → `contacts`.
- Форма пока показывает подтверждение без реальной отправки. Для приёма заявок
  можно подключить Formspree, Telegram-бота или отправку на почту — место отмечено
  в `app.js` (функция `initForm`).

## Картинки

Положите изображения в `assets/img/` и укажите пути в `data.js`.
Рекомендуемый формат обложек — 16:9, оптимизированные JPG/WebP.
